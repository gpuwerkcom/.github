# GPUwerk

We rent dedicated NVIDIA GPUs by the minute: one customer per machine, never a
slice of a shared GPU, no egress fees. Terminate when you are done and billing
ends.

## What we rent

| GPU | Memory | Architecture |
|---|---|---|
| DGX Spark (GB10), single node | 128 GB unified | ARM64 |
| DGX Spark, linked two-node cluster | 2 × 128 GB | ARM64 |
| DGX Spark (partner-hosted) | 128 GB unified | ARM64 |
| RTX 5090 | 32 GB GDDR7 | x86 |
| RTX 6000 Ada | 48 GB GDDR6 ECC | x86 |
| L40S | 48 GB GDDR6 | x86 |
| RTX PRO 6000 Blackwell | 96 GB GDDR7 ECC | x86 |
| H100 SXM | 80 GB HBM3 | x86 |
| 8× H100 / 8× B200 servers | per server | x86, quoted monthly |

x86 GPUs are first come, first served: deploy one when it is free, or join its
waitlist. Current prices and availability: [gpuwerk.com/gpus](https://gpuwerk.com/gpus).
